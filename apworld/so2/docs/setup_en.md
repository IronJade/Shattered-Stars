# Star Ocean: The Second Story (Shattered Stars) setup

1. Get Shattered Stars and run its setup program. Choose your own Star Ocean: The Second
   Story discs (PlayStation, North American release).
2. Put this world (`so2.apworld`) in Archipelago's `custom_worlds` folder, write a YAML
   with `game: Star Ocean: The Second Story`, and generate.
3. The output has one `.apso2` file per Star Ocean player. In the setup program, choose that
   file, the server address, your slot name and the password, then start the game.
4. Start a New Game with the protagonist your YAML names (`protagonist`).
