# Reference: Shops

Every shop's stock, entry by entry. A shop's number is what `so2_mod.py shop` takes (a name of a map that opens it works too), with the entry's index:

```
python3 tools/so2_mod.py shop DISC.cue SHOP INDEX ITEM   # replace entry INDEX
python3 tools/so2_mod.py shop DISC.cue SHOP add ITEM     # add an entry at the end
python3 tools/so2_mod.py shop DISC.cue SHOP INDEX 0      # remove entry INDEX
```
