# Menu worker: continuation log

This is the running log for the field menu port (phase M6). Read it first when you pick
up the work. It is updated after every finished step.

Rules that apply to every step:

- Build only in `engine/build-menu`.
- Run the game headless with `SDL_VIDEO_DRIVER=offscreen` and `SDL_AUDIO_DRIVER=dummy`.
- Never pass `--no-audio`, `--audio` or any other flag that saves config.
- Run Redux only with `-cli` and the isolated `XDG_CONFIG_HOME` in `scratchpad/menu/redux/xdg`.
- Put scratch files in `scratchpad/menu/`, never in /tmp.
- Kill processes only by exact PID.
- Never commit; the coordinator commits.
- Catalog every reversed function in `analysis/menu_catalog`. Rows are generated by
  `scratchpad/menu/gen_catalog.py`: edit that script, then run it.
