# Shattered Stars 0.01.00

The first release of Shattered Stars: a native Windows and Linux port of *Star Ocean: The
Second Story*, hand-written in C++20 on top of SDL3 and OpenGL. It is not an emulator — no
PlayStation code runs — and it ships no game data. You need your own disc images to play.

**You need your own North American discs:** SCUS-94421 (Disc 1) and SCUS-94422 (Disc 2), as a
`.cue` with its `.bin`, or an `.iso` / `.img`. European and Japanese discs, and compressed
formats such as CHD or PBP, aren't accepted yet. Disc 2 is optional until the story asks for
it.

## Highlights

- **Checked against the original, not by eye.** Every system was compared with the original
  game running in PCSX-Redux: frames, battle random-number draws, unit positions and damage,
  sound driver calls and save data.
- **Full speed, instant loading.** No slowdown when the screen gets busy, no waiting for the
  disc.
- **Bugs fixed, gameplay untouched.** 83 cases in the original's code are documented, each
  fixed only where the fix leaves hit timing, damage, difficulty and pacing exactly as they
  were, measured against the original.
- **Saves that travel.** Memory card images are byte-compatible with the console's; DexDrive
  saves convert in the setup program.
- **Modern controls and display.** Keyboard or gamepad, every button rebindable, analog
  walking and rumble; windowed, borderless or exclusive full screen, with optional
  PlayStation-style dithering and vertical sync.
- **Archipelago built in.** The multiworld client is part of the game itself — no separate
  client program.
- **Mods that never touch your discs.** Guarded patch files change chests, doors, items, shops
  and enemy stats as the game loads, managed from the setup program.
- **A setup program.** Choose and verify your disc images, and set display, sound, controls,
  memory cards, mods and Archipelago in one window.

## Installing

1. Unpack the package for your platform anywhere.
2. Run the setup program: `setup.exe` on Windows, `./shattered-stars-setup` on Linux.
3. On the **Discs** page, choose Disc 1 and Disc 2 with **Browse...**, or put your images in
   the `discs` folder next to the game and press **Auto-detect**. Setup checks each image and
   says whether it is the right disc.
4. Press **Save & Play**.

After that, start the game directly with `shattered-stars.exe` or `./shattered-stars`.
Settings, memory cards and mods live in your user folder, so a later version can replace this
one without touching them.

Full details: [Installing and Setup](https://github.com/IronJade/Shattered-Stars/wiki/Installing-and-Setup)
and [Playing](https://github.com/IronJade/Shattered-Stars/wiki/Playing) on the wiki.

## Archipelago

Shattered Stars has the [Archipelago](https://archipelago.gg) client built into the game — no
separate client program is needed. This world is custom and **not yet part of Archipelago
itself**, so it ships here as a separate `.apworld`:

1. Copy `so2.apworld` into the `custom_worlds` folder of **Archipelago 0.6.8 or newer**.
2. Make your options YAML, either with the Archipelago Launcher's **Options Creator** (pick
   *Star Ocean: The Second Story* and set options with buttons and sliders) or by hand, starting
   from `Star Ocean The Second Story.yaml`.
3. Generate as usual. Each Star Ocean player gets a seed file ending in `.apso2`.
4. In the setup program's **Archipelago** page, choose the seed file and enter the room's
   address, your slot name and password. Press **Save & Play**; the game connects as it
   starts.

Details, every option, and troubleshooting: [Archipelago](https://github.com/IronJade/Shattered-Stars/wiki/Archipelago)
on the wiki.

## Known limitations

- **North American discs only.** SCUS-94421 / SCUS-94422. European and Japanese releases, and
  compressed disc formats (CHD, PBP), are not accepted yet.
- **No macOS build.**
- **The Archipelago world is not yet in Archipelago itself.** Until it's merged upstream, get
  `so2.apworld` and its template from this project's releases, not the Archipelago Launcher's
  own world list.
- **The curated mod list is small.** Two sample mods ship today; see the
  [Modding](https://github.com/IronJade/Shattered-Stars/wiki/Modding) wiki page to make or
  submit your own.

See [Bugs Fixed and Quirks Kept](https://github.com/IronJade/Shattered-Stars/wiki/Bugs-Fixed-and-Quirks-Kept)
for what was changed from the original and what was deliberately left as it was.
