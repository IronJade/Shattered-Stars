# Maps with random encounters

Found by starting every field map with the port's `--map N` debug option (new game as Claude) and
logging the encounter settings each map's script sets on entry (`field_flags` +0x25 rate, +0x14 group,
+0x12 stage; field_update state 0). Maps that only enable encounters later (after an event, or
under story flags a new game lacks) are not listed. Group = index into the encounter group
table at field 0x80074fe0 (0-terminated s16 encounter lists); stage = battle background
(load list entry 0x543 + stage).
